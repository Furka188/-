# Face Biometry Lab — Premium

Премиальный черно-белый веб-сервис биометрического анализа лица.

## Что улучшено

- Расширенная метрика лица: геометрия, пропорции, симметрия, нормализованные коэффициенты.
- Оценка качества снимка: яркость, контраст, резкость (Laplacian variance).
- TXT-досье с 3 секциями: метрики, quality envelope, полный список landmark-точек.
- Режим сравнения 2 фото:
  - детальный diff по каждой метрике;
  - top distinguishing landmarks (самые отличающиеся точки).
- Премиальный монохромный UI без «вайб-кодерского» минимализма.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Открыть: `http://127.0.0.1:5000`

## Сборка ZIP для скачивания

```bash
zip -r face-biometry-lab-premium.zip . -x ".git/*" -x ".venv/*" -x "outputs/*" -x "uploads/*" -x "__pycache__/*"
```

После команды архив `face-biometry-lab-premium.zip` будет в корне проекта.

Также в веб-интерфейсе доступна прямая ссылка `GET /download/project-zip`, которая собирает и отдает ZIP автоматически.

## Важно

Проект предоставляет технический биометрический анализ по фото и не является официальной судебно-экспертной идентификацией.
